# VEDA Task 23 – SQL Window Functions

## Project Overview

This project focuses on practicing SQL window functions using PostgreSQL and the Northwind database. It demonstrates how window functions can analyze data while preserving individual rows.

## Tools Used

* PostgreSQL
* pgAdmin 4
* Northwind Database
* GitHub

## Concepts Covered

* ROW_NUMBER()
* RANK()
* DENSE_RANK()
* LAG() and LEAD()
* SUM() OVER()
* AVG() OVER()
* PARTITION BY
* Customer-wise sales analysis
* Order ranking and comparison

## Project Files

* `VEDA_Technology_task_23_window_functions.sql` – SQL queries with comments explaining each question.
* `Business_Insights.txt` – Key findings and practical uses of window functions.
* `Outputs/` – Screenshots showing query results.

## Key Learnings

* Ranking products and orders.
* Comparing current, previous, and next orders.
* Calculating running totals and averages.
* Analyzing customer-wise sales.
* Identifying the latest orders for each customer.

## Conclusion

This task strengthened my understanding of SQL window functions and their applications in data analysis.
